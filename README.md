# 생존앱 — 성남·서울 초등학교 채용공고 알림

성남 초등학교 74곳 + 성남교육지원청 + **서울 11개 교육지원청 구인게시판** + 양성교육(디지털튜터·AI강사)을
매일 자동 점검해서 새 공고를 텔레그램·메일로 알려주는 앱.

- 웹: https://waymaker1018.github.io/seongnam-survival-map/ (성남) · `/seoul/` (서울)

## 성남 지도 화면

성남 지도는 수원 강사 채용 맵과 같은 화면 구성을 사용합니다. 모집 공고, 학교 한눈맵, 양성교육·전국 채용, 수집 현황을 탭으로 전환할 수 있습니다. 학교·공고 검색, 분야·구·동·연도·접수 상태·출처 필터, 관심 공고 저장, CSV·JSON 내려받기를 지원합니다.

기존 관심 학교는 같은 브라우저에서 그대로 유지됩니다. 학교 한눈맵에서 구 경계를 누르거나 구·동 필터를 선택해 범위를 좁힐 수 있습니다. 성남 명부는 초등학교를 대상으로 하며, 전국 채용 자료는 별도 탭에 표시합니다.

성남 화면의 코드는 `index.html`과 `ui/`에 있습니다. `ui/data.js`가 기존 `data/` 파일을 읽어 화면에 맞게 변환하므로 자동 수집 후 별도 빌드가 필요하지 않습니다. UTC 시각은 한국 날짜로 변환하며, 같은 원문 링크만 묶고 접수일이 충돌하면 원문 확인 대상으로 표시합니다. 수집 현황에는 실제 파일에 있는 정보만 표시합니다.

서울 화면은 기존 `seoul/index.html`, `app.js`, `styles.css`를 계속 사용합니다. 검증은 `npm test`, 로컬 실행은 `npm run serve`로 할 수 있습니다.

별도로 조사한 2026년 디지털튜터 공고(`data/seongnam_digital_tutor_2026.json`)도 모집 목록에 합쳐 표시합니다. 초등학교 명부에 있는 학교는 지도·지역 필터에 연결하고, 교육지원청 통합 모집과 중학교 공고는 목록에서 원문으로 확인할 수 있습니다. 분야 옆 숫자는 마감 공고를 포함한 수집 공고 수이며, 모집 인원이나 최종 채용 인원이 아닙니다. 이 자료는 성남 전체 공고를 빠짐없이 집계한 통계가 아닙니다.

### 학교 설립 구분

공고 카드·상세 화면·학교 지도·CSV에는 공립·사립 등 설립 구분을 표시합니다. `npm run collect:establishments`로 나이스 학교기본정보를 확인해 `data/school_establishments.json`을 갱신합니다. 대상은 등록 학교와 디지털튜터 통합 공고의 학교이며, 학교명과 성남시 주소가 일치하는 자료만 연결합니다. 여러 학교의 통합 공고는 설립 구분이 섞여 있으면 ‘공립·사립 혼합’, 확인할 수 없으면 ‘설립 구분 미확인’으로 표시합니다. 상세 화면에서 출처와 확인일을 볼 수 있습니다. 설립 구분은 계약 상대방이나 겸직 가능 여부를 보장하지 않습니다.

### 첨부파일 미리보기

공고 상세의 첨부파일에서 **미리보기**를 누르면 사이트 안의 큰 창에서 문서를 읽을 수 있습니다. 창 안의 **새 창에서 보기** 또는 **공고 원문**으로 이동할 수도 있습니다. 닫기 버튼이나 Esc 키로 목록에 돌아옵니다.

`npm run collect:previews`는 최근 성남 공고의 공식 미리보기 연결을 확인하여 `data/attachment_previews.json`에 파일명과 공개 뷰어 주소를 저장합니다. 원본 문서, 문서 본문, 기관 인증 값은 저장하지 않습니다. 기존 일일 점검에도 이 단계가 포함되어 새 공고에 적용됩니다. 과거 모집 이력까지 보충하려면 `npm run collect:previews -- --all`을 실행합니다.

현재는 성남교육지원청과 같은 `goesn.kr` 학교 사이트에서 제공하는 문서 뷰어를 지원합니다. 미리보기가 제공되지 않거나 아직 수집하지 않은 과거 공고에는 원문 안내를 표시합니다. 외부 뷰어의 링크 만료나 변환 오류가 발생할 때도 공고 원문에서 다시 확인할 수 있습니다.

## 빠른 시작

```powershell
npm run serve     # 지도 앱 → http://localhost:4173
npm run daily     # 크롤링 + 알림 수동 실행
```

자동 실행은 작업 스케줄러 `성남채용알림_일일점검` (매일 09:00, 15:00)에 등록되어 있음.

**알림을 받으려면 `config/notify_config.json` 설정 필요** — 자세한 내용은 [production_plan.md](production_plan.md) 참고.
