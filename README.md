# 생존앱 — 성남·서울 초등학교 채용공고 알림

성남 초등학교 74곳 + 성남교육지원청 + **서울 11개 교육지원청 구인게시판** + 양성교육(디지털튜터·AI강사)을
매일 자동 점검해서 새 공고를 텔레그램·메일로 알려주는 앱.

- 웹: https://waymaker1018.github.io/seongnam-survival-map/ (성남) · `/seoul/` (서울)

## 성남 지도 화면

성남 지도는 수원 강사 채용 맵과 같은 화면 구성을 사용합니다. 모집 공고, 학교 한눈맵, 양성교육·전국 채용, 수집 현황을 탭으로 전환할 수 있습니다. 학교·공고 검색, 분야·구·동·연도·접수 상태·출처 필터, 관심 공고 저장, CSV·JSON 내려받기를 지원합니다.

기존 관심 학교는 같은 브라우저에서 그대로 유지됩니다. 학교 한눈맵에서 구 경계를 누르거나 구·동 필터를 선택해 범위를 좁힐 수 있습니다. 성남 명부는 초등학교를 대상으로 하며, 전국 채용 자료는 별도 탭에 표시합니다.

성남 화면의 코드는 `index.html`과 `ui/`에 있습니다. `ui/data.js`가 기존 `data/` 파일을 읽어 화면에 맞게 변환하므로 자동 수집 후 별도 빌드가 필요하지 않습니다. UTC 시각은 한국 날짜로 변환하며, 같은 원문 링크만 묶고 접수일이 충돌하면 원문 확인 대상으로 표시합니다. 수집 현황에는 실제 파일에 있는 정보만 표시합니다.

서울 화면은 기존 `seoul/index.html`, `app.js`, `styles.css`를 계속 사용합니다. 검증은 `npm test`, 로컬 실행은 `npm run serve`로 할 수 있습니다.

## 빠른 시작

```powershell
npm run serve     # 지도 앱 → http://localhost:4173
npm run daily     # 크롤링 + 알림 수동 실행
```

자동 실행은 작업 스케줄러 `성남채용알림_일일점검` (매일 09:00, 15:00)에 등록되어 있음.

**알림을 받으려면 `config/notify_config.json` 설정 필요** — 자세한 내용은 [production_plan.md](production_plan.md) 참고.
